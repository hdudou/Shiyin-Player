# 拾音 · 多功能音乐播放器（开源版）

拾音是一款面向安卓的本地 + 网络音乐播放器，内置 ZeroTier 虚拟网接入与网络收音机。应用通过本地、WebDAV、SMB 三类音乐源组织曲库，并把 ZeroTier 的 libzt 用户态栈打包进应用，无需系统 VPN 权限即可在播放器内加入虚拟局域网，跨网络访问家中 NAS 的音乐。

本仓库是从作者自用版脱敏后的开源副本：**不内嵌任何私有网络 ID、默认音乐源或更新服务器**，也没有版本自动更新与内置电台远程同步，所有接入均由使用者自助配置。当前界面为中文（含英文语言包）。

---

## 功能概览

- **完整曲库**：底部导航包含 歌曲 / 专辑 / 艺术家 / 播放列表 / 更多；标签页固定顺序为 歌曲 → 文件夹 → 专辑 → 艺术家。支持歌曲 / 专辑 / 艺术家多选、批量播放、批量加入歌单，以及全局搜索（含拼音 / 首字母匹配，搜索结果可批量选择播放或加歌单）。
- **多音乐源**：本地存储（媒体库 + 全盘文件访问）、WebDAV、SMB 三类来源扫描入库，支持增量 / 全量更新；SMB 支持「浏览局域网」自动发现主机（含手动输入回退），进入主机时询问账号密码或匿名访问。
- **ZeroTier 虚拟网**：应用内直接加入 ZeroTier 网络（libzt 用户态，非系统 VPN），跨公网访问虚拟网内 WebDAV / SMB 服务器。网络 ID 需自行填写。
- **元数据刮削**：自动 / 手动同步音乐与歌词元数据（专辑封面、歌手信息、在线歌词），可配置来源与优先级（网易云 / QQ 音乐 / 酷我 / 咪咕 / 酷狗），详见「元数据刮削」章节。
- **网络收音机**：HLS / 网络流电台，内置按 大陆 / 港澳台 / 海外 分类的电台清单（含多线路），支持线路自动切换、手动选线、电台搜索与自定义电台。
- **音频格式广**：基于 Media3（ExoPlayer），覆盖 mp3 / aac / ogg / wav / flac / opus / ac3 / dts / aiff / alac 等常见格式；FFmpeg 软解（NDK）进一步支持 ape / wma / wv / tta / tak / mpc / ofr / oma / dsf / dff 等无损与罕见格式。
- **歌词与可视化**：内嵌歌词读取、在线歌词匹配、桌面歌词悬浮窗、车载蓝牙歌词、锁屏动态可视化叠加层。
- **播放控制**：后台前台服务播放、通知栏媒体控制、有线 / 蓝牙耳机按键、有线拔出自动暂停、蓝牙断开自动暂停、音频焦点管理、睡眠定时与定时播放（音乐与收音机统一「定时」入口）。
- **声音引擎**：均衡器与按流派自动 EQ、音量归一化、回放增益（ReplayGain）、无缝播放。
- **数据备份**：播放器数据导出 / 导入（系统设置、曲库、歌单可选），可选用 AES-256-GCM 加密保护。

> 投屏（Cast / AirPlay / DLNA）、版本更新、内置电台远程同步、HTTP 直连源等功能在开源版中已移除，不再提供。

## 技术栈

| 类别 | 选型 |
|---|---|
| 语言 / UI | Kotlin + Jetpack Compose（Material3） |
| 依赖注入 | Hilt |
| 数据库 / 存储 | Room、DataStore Preferences |
| 播放内核 | Media3（ExoPlayer 1.4.1），含 HLS |
| 软解 | FFmpeg 6.1（NDK 交叉编译）+ 自研 AVIO JNI、vendored media3 decoder_ffmpeg |
| 网络源 | jcifs-ng（SMB）、OkHttp 手写 PROPFIND（WebDAV） |
| 凭据加密 | security-crypto（EncryptedSharedPreferences） |
| 虚拟网 | libzt（ZeroTier 用户态） |
| 图片加载 | Coil |

构建配置：AGP 8.5.2、Kotlin 1.9.24、Gradle 8.9、JDK 17、CMake 3.22、支持 ABI `arm64-v8a` 与 `armeabi-v7a`，`minSdk 24`（Android 7.0）/ `targetSdk 34`。

```
app/src/main/
├── java/com/shiyinplayer/
│   ├── player/                 # 播放内核：PlaybackController、PlaybackService、PlayerManager
│   │   └── radio/              # 收音机内核（HLS、多线路、定时/闹钟）
│   ├── data/
│   │   ├── local/              # Room DAO / 实体
│   │   ├── media/              # 音乐源扫描、播放源工厂、曲目解析
│   │   ├── metadata/           # 元数据刮削：网易/QQ/酷我/咪咕/酷狗/Wikipedia 等来源
│   │   ├── metasync/           # 元数据（歌词/封面）异步匹配与后台同步服务
│   │   ├── network/zerotier/   # ZeroTier 接入（libzt 节点管理、路由映射）
│   │   └── remote/webdav/      # WebDAV 浏览 / 数据源
│   └── ui/                     # Compose 界面：歌曲/专辑/艺术家/歌单/更多/收音机/设置/ZeroTier/锁屏
├── cpp/                        # FFmpeg JNI（ffmpeg_jni.c / ffmpeg_official_jni.cc）+ CMake 与预编译库
├── jniLibs/                    # 预编译原生库（libzt.so、libav*.so、FLAC/Opus/Oboe 等）
└── assets/                     # 内置电台清单、版本更新记录
```

原生依赖（FFmpeg 库、libzt 与各编解码 `.so`）已内置在仓库中，可直接构建，无需预先编译 NDK 产物。FFmpeg 自构建脚本见 `scripts/`。

## 构建

### 环境要求

- JDK 17（需含 `jlink`，供构建插件的 `androidJdkImage` 变换使用）
- Android SDK（`compileSdk 34`，`build-tools 34.x`）
- Gradle 8.9（仓库已带 `gradlew` wrapper，自动下载）

仓库默认通过 `gradlew` 构建。Gradle 依赖仓库已切为阿里云镜像（见 `settings.gradle.kts`），如你的网络可直连 Google Maven，可自行改回 `google() / mavenCentral()`。

### 步骤

```bash
# 调试包（applicationId=com.shiyinplayer.debug）
./gradlew :app:assembleDebug

# 发布包（applicationId=com.shiyinplayer）
./gradlew :app:assembleRelease

# 产物
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/app-release.apk
```

若 `gradlew` 因 JDK 定位失败，显式指定 `JAVA_HOME` 指向你的 JDK 17，或在 `gradle.properties` 中取消 `org.gradle.java.home` 注释并填入本地路径。

### 签名注意

`release` 构建类型当前**占位复用 debug keystore** 签名，仅便于本地直接打包调试。正式发布前请在 `app/build.gradle.kts` 中替换为自有 keystore，并在 `local.properties`（已 gitignore）或环境变量中配置 `storeFile / storePassword / keyAlias / keyPassword`。严禁将私钥文件提交进仓库。

## 使用入门

### 1. 安装与首次启动

构建 APK 或在发布渠道下载安装。首次启动会依次请求运行所需权限；因权限用途各异，详见下方「运行时权限」。

### 2. 添加音乐源

所有音乐源在 **「更多 → 音乐库 → 音乐库来源管理」** 中统一管理。点右上角「添加来源」，先选择来源类型（SMB / WebDAV / 文件夹），再按类型补全信息：

- **文件夹（本机）**：无账号密码。点「浏览文件夹」直接调用系统目录选择器选择本机目录即可（需先授予「所有文件访问」权限）。也可手动输入本地绝对路径，如 `/storage/emulated/0/Music`。
- **WebDAV**：填写服务器**地址**（如 `https://dav.example.com/dav`），可选的**用户名 / 密码**用于受限目录。凭据经系统加密存储。
- **SMB**：填写形如 `smb://192.168.1.10/Music` 的地址与账号密码；更常用的方式是点 **「浏览局域网」** 自动发现局域网内开启 SMB 的主机：
  1. 面板会先显示扫描动画并在结束后列出发现到的主机（未发现时提示可手动输入主机 IP）；
  2. 点某台主机，若需要凭据会弹出**用户名 / 密码（或勾选匿名访问）**对话框；
  3. 连接成功后可逐级进入共享目录，面板右上角提供**返回上一级**；
  4. 选中目标目录后点 **「使用此目录」**，其路径与刚才输入的账号密码会自动回填到添加表单。

保存后回到来源列表，对该来源执行 **扫描 / 同步** 即可入库。扫描支持两种方式：**只扫描新增内容**（默认，保留现有曲目）或**全部扫描并更新已有内容**（按去重键覆盖、可修复因服务器地址或凭据变更导致的条目失效）。

> 提示：若 SMB / WebDAV 服务器在公网另一端，可先接入 ZeroTier，再用虚拟网 IP 作为来源地址（见下节）。

### 3. 接入 ZeroTier（可选）

在 **「更多 → ZeroTier 虚拟网络」** 填入你的 Network ID 并加入，再到 ZeroTier 官方控制台把该节点批准（Authorize）到网络。加入成功后应用内即可用虚拟网内 IP 访问 NAS 的 WebDAV / SMB。开源版不提供任何默认网络，需自行注册 ZeroTier 账号创建。

### 4. 组织与播放曲库

- 底部「歌曲 / 文件夹 / 专辑 / 艺术家」四个标签页分别按维度浏览；「播放列表」页管理歌单与最近播放 / 最常播放 / 随机播放智能列表。
- 点一次单曲立即播放；长按或进入选择模式可**多选**，底部出现播放全部、加入歌单等批量操作；歌单右上角「⋮」支持新建，长按歌单可播放 / 重命名 / 删除。
- 顶部搜索框支持全局搜索（含**拼音 / 首字母**匹配），搜索结果可逐项或批量选中后立即播放 / 加入歌单。
- 播放页支持队列、拖拽排序、无缝播放、倍速、循环与音质相关设置。
- **模式切换**：底部导航中央的「播放 / 切换」按钮，单击进入正在播放页（或开始播放），**双击**在 音乐播放器 ↔ 收音机 两种模式间切换；横屏左侧导航的播放按钮行为相同。

### 5. 收听网络收音机

在应用中切换到收音机模式：可选择内置电台（按 大陆 / 港澳台 / 海外 分类，多线路），也可搜索或自定义电台 / 手动输入流地址。播放时某线路卡顿会自动切换下一条线路，也可在播放页手工换线。

### 6. 歌词与可视化

- 歌词优先读取文件**内嵌歌词**（UTF-8 / UTF-16 / GBK 自动识别），缺失时在线匹配并缓存。
- 支持桌面歌词悬浮窗（需「显示在其他应用上层」权限）、车载蓝牙歌词（车载设备同步显示当前行）。
- 锁屏页提供动态可视化叠加层（需录音权限），上滑可退出。

### 7. 声音引擎

在 **「更多 → 声音引擎设置」** 中可开启均衡器与按流派自动 EQ、音量归一化、ReplayGain、静音消除等；无缝播放在相应设置项开启。

### 8. 数据备份

在 **「更多 → 播放器数据导出/导入」** 可将系统设置（含网络和源设置、登录凭据）、曲库条目（含元数据）与歌单导出为单个数据文件；可按需勾选导出范围，并可选加密（AES-256-GCM）。导入时需确认覆盖的数据类型，加密文件需输入导出时的密码。

### 运行时权限

应用所需权限均按用途在首次用到时申请，主要包括：

| 权限 | 用途 |
|---|---|
| `MANAGE_EXTERNAL_STORAGE` | 访问未入媒体库的本地音频（Android 11+ 走「所有文件访问」特殊权限） |
| `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` | 读取本地媒体库音频 |
| `POST_NOTIFICATIONS` | 播放控制通知（Android 13+） |
| `BLUETOOTH_CONNECT` | 蓝牙耳机媒体控制与车载歌词 |
| `SYSTEM_ALERT_WINDOW` | 桌面歌词悬浮窗 |
| `RECORD_AUDIO` | 锁屏可视化层音频捕获 |

## 元数据刮削

应用会对曲库条目补全**标题 / 歌手 / 专辑 / 年份 / 封面 / 歌词**等元数据，有两种方式：

### 自动刮削

在 **「更多 → 元数据设置」** 中配置并开启：

- **读取内嵌歌词**：优先使用歌曲文件内嵌的歌词标签（缺失部分才联网补充）。
- **在线元数据**：控制是否联网获取专辑封面、歌手头像与简介。
- **元数据来源**：选择启用的在线来源并设置优先级（网易云 / QQ 音乐 / 酷我 / 咪咕 / 酷狗等）。多来源按优先级依次尝试，失败自动回退下一来源。
- **自动同步音乐元数据**：开启后，应用在后台自动批量同步曲库中缺失的元数据 / 歌词，结果写入本地缓存（含有效期，过期条目懒式清理），无需人工干预。
- **数据传输节省**：可设置在移动网络下不联网获取元数据 / 歌词，仅在 WiFi 下自动同步。

### 手动刮削

当自动同步未覆盖、或需要对个别条目纠错时：

- **单曲级**：在歌曲列表 / 播放页对某首歌打开操作菜单，选 **「在线查找元数据」** 立即从启用来源匹配并补全；也可选 **「编辑元数据」** 手工填写标题 / 歌手 / 专辑 / 年份等字段。修改后列表即时刷新。
- **全库级**：在 **「更多 → 元数据设置 → 批量同步元数据」** 手动触发，立即对全库（任意来源）缺失元数据的曲目做一次多线程并发、多来源采集（全程限速，不打挂在线服务器），适合一次导入大量曲目后补全。

> 说明：元数据全部来自歌曲文件内嵌标签与公开第三方接口，版权归相应提供商所有；仅供个人整理曲库使用。部分来源为第三方服务，可用性取决于对方接口，应用不保证持续可用。
